    AI 時代，本科資訊人的核心競爭力：技術選型（Technology Selection）

    資訊人核心競爭力 ⏱️ 閱讀時間 7 分鐘

    💡 本章核心觀念

    生成式 AI 大幅降低了程式開發的門檻，也改變了資訊人員的價值。
    未來資訊人的核心能力，將逐漸從「寫程式」轉向「選技術（Technology Selection）」。

    一、價值轉向：工程師競賽規則的改變

    過去，資訊工程師主要比的是：誰會更多程式語言、誰程式寫得更快、誰熟悉更多 Framework。

    然而 AI 已能協助完成大量程式撰寫工作。未來真正重要的不再是「我會不會寫 Python？」，而是：「這個問題最適合用什麼技術解決？」

    🌐 HTML / Web UI 🐍 Python Engine ☁️ Cloudflare Workers 📊 Google Apps Script 🗄️ SQL 🔄 n8n 自動化 🤖 AI Agent ⚡ Workflow 🔌 各種 AI API
    🎯 好的工程師思維：

    每一種工具都有自己的優勢與適用場景。優秀的工程師，不是每件事情都使用同一種技術，而是能選擇最適合的方案。

    二、技術選型，比技術本身更重要

    在 AI 時代，許多技術都能完成同一件事情。真正的差異在於：

    1 開發速度與維護成本

    是否能用最少的程式碼、最低的複雜度維護系統。

    2 執行效率與擴充能力

    架構是否具備彈性，能隨業務需求水平擴充。

    3 團隊協作與溝通

    標準化規格是否能讓團隊快速接手與分工。

    4 長期維運成本 (TCO)

    計算雲端託管、伺服器與授權之總體擁有成本。

    三、ERP 企業系統更需要技術選型能力

    企業級 ERP 系統很少只依賴單一技術。真正的企業系統，是許多技術共同合作完成：

    • 🖥️ 人機介面 UI ➔ 採用 HTML
    • 🧠 AI 推理與 OCR ➔ 採用 Python
    • 🔄 工作流程處理 ➔ 採用 Workflow 引擎
    • ⏱️ 定時排程任務 ➔ 採用 Cloudflare Cron
    • 🏭 ERP 串接與溝通 ➔ 採用 REST API
    • 📊 報表與資料視覺化 ➔ 採用 HTML / PowerBI

    四、AI Native 工程師不可被取代的 5 大關鍵能力

    未來優秀的資訊人員，除了基礎程式能力，更需要具備以下難以被 AI 完全取代的核心價值：

    • 🏛️ 架構設計 (Architecture)：規劃高可用與鬆耦合之整體系統藍圖。
    • 🎯 技術選型 (Technology Selection)：在眾多工具中找出最佳成本效益解。
    • 🤝 AI 協作能力 (Human + AI)：高效指揮 AI Agent 協助產出程式碼。
    • 💰 成本與效益分析 (ROI)：為企業計算開發與維運的投資報酬率。
    • 🛡️ 系統治理與維運 (Governance)：資訊安全、合規性與維護品質控管。
    「 AI 降低了寫程式的門檻，但提高了技術選型的重要性。
    未來的競爭力，不再只是『會不會寫程式』，而是是否能在眾多技術與 AI 工具之間，選擇最適合的解決方案！」
