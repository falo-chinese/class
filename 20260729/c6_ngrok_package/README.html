❓ 學員常見問題 (FAQ & Troubleshooting)

Q1: 為什麼點擊對外網址出現 ERR_NGROK_8012 錯誤？
代表 ngrok 已連通，但您電腦上的 Python 服務還沒啟動！請記得先雙擊 start.bat（保持視窗開啟），再開啟 ngrok 網址。
Q2: ngrok 的網址每次重啟都會變嗎？
是的！ngrok 免費版每次重啟會生成全新的隨機 URL。這正是為什麼 ngrok 被定位為「開發與 Quick Demo 練兵神器」；若企業需要永久固定域名，建議採用 Cloudflare Tunnel 方案。
Q3: 如何即時監控外部打進來的 API 請求？
ngrok 啟動後，請在瀏覽器開啟 http://127.0.0.1:4040，即可看到本機即時的 Traffic Inspector 儀表板，實時觀察請求的 Header 與 JSON 內容。
